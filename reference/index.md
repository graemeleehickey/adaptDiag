# Package index

## Simulation

Simulate and analyse multiple adaptive diagnostic trials.

- [`multi_trial()`](https://graemeleehickey.github.io/adaptDiag/reference/multi_trial.md)
  : Simulate and analyse multiple trials
- [`summarise_trials()`](https://graemeleehickey.github.io/adaptDiag/reference/summarise_trials.md)
  : Summarise results of multiple simulated trials to give the operating
  characteristics

## Sample size

Calculate sample sizes for exact binomial tests.

- [`binom_sample_size()`](https://graemeleehickey.github.io/adaptDiag/reference/binom_sample_size.md)
  : Calculate the minimum number of samples required for a one-sided
  exact binomial test
